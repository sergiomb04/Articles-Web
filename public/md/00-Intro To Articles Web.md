# Brief Description

**Articles-Web** is a tool that I developed to read, organize, and display articles written in Markdown in an elegant and functional way. It is designed to be **modular, open-source, and fully customizable**, so you can adapt it to your own projects or use it as-is.

---

## What Articles-Web Offers

1. **Markdown Rendering:** Converts `.md` files into interactive web pages.
2. **Rich Components:** Supports tables, images, videos, accordions, and tabs.
3. **SEO and Automatic Navigation:** Friendly slugs, automatic meta tags, and built-in search.
4. **Extensible:** You can add your own components or styles without complications.
5. **Open Source:** All code is publicly available for you to use, modify, or distribute.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/sergiomb04/Articles-Web.git
```

2. Install dependencies and start the server:

```bash
cd Articles-Web
npm install
npm run dev
```

3. Create your Markdown articles and place them in the `public/md` folder. That's it — your content will be rendered automatically!
